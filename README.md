# Autonomous Website Generation & Management System (AGMS)
## Strategic Product Requirement Document (PRD)

### 🚀 Overview
This project defines the architecture for an AI-agent workforce designed to manage 180+ medical clinic websites. It addresses the transition from manual labor to an autonomous pipeline using SOTA open-source models.

### 💰 The Business Case
* **Annual Savings:** ₹1.80 Cr (based on replacing/redeploying 9-12 developers).
* **Target Efficiency:** 85% reduction in man-hours per site update.
* **Architecture:** Evaluates Sovereign, Hybrid, and Orchestration stacks.

### 🛠️ Tech Stack Featured
* **Orchestration:** CrewAI
* **Reasoning:** DeepSeek-R1-Distill-Qwen-7B
* **Coding:** Qwen2.5-Coder-32B
* **Monitoring:** Langfuse & Custom "Observer" Middleware
